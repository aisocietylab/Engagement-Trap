The site is a Jekyll project in `docs/`, published with GitHub Pages from the `/docs` folder on `main`. The layout comes from the remote theme [`aisocietylab/group-website-pages`](https://github.com/aisocietylab/group-website-pages).

## Site files

- `docs/index.md`: homepage content (authors, abstract, links, BibTeX)
- `docs/_config.yml`: title, URL, and theme
- `docs/_data/navigation.yml`: top navigation
- `docs/assets/`: images and PDFs used on the page
